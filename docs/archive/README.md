These files remain useful as evidence and design history, but they are not current execution instructions.

Use the canonical documents one directory above for current work:

- `../GAME_SPEC.md`;
- `../ARCHITECTURE.md`;
- `../BALANCE.md`;
- `../ROADMAP.md`.

If an archived report conflicts with a canonical document, the canonical document wins unless a new verified change updates it.
